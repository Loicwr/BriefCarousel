
# 🎠 Mini Carousel  
Bienvenue sur **Mini Carousel**, un projet simple mais efficace qui met en scène un carrousel d’images interactif. Développé dans un esprit pédagogique, ce mini site démontre comment créer une fonctionnalité d'affichage dynamique d’images avec du JavaScript pur.

---

## 🌟 Objectif du projet  

Mini Carousel a été imaginé pour :

- Illustrer le fonctionnement d’un carrousel d’images sans dépendances externes  
- Apprendre à manipuler le DOM avec JavaScript  
- Proposer un petit composant réutilisable dans d'autres projets (portfolio, galerie, etc.)  
- Mettre en pratique une structuration HTML/CSS propre et responsive  

---

## 💻 Technologies utilisées  

- HTML5  
- JavaScript Vanilla  
- CSS3 / SASS (précompilé dans `main.css`)  

---

## 🧠 Fonctionnalités clés  

- Navigation fluide entre les images (Précédent / Suivant)  
- Affichage conditionnel des images avec une seule visible à la fois  
- Accessibilité via `aria-labels`  
- Design adaptable (prévu pour s'intégrer facilement dans un site existant)  
- Code modulaire, simple à personnaliser  

---

## 🖼️ À propos des images  

Le projet utilise une série d’images situées dans le dossier `/assets`. Ces visuels sont affichés automatiquement dans le carrousel grâce à un tableau dynamique dans le script.

---

## 👨‍💻 À propos du projet  

Mini Carousel est un projet front-end léger, parfait pour s’initier à l’interactivité web sans framework. Il peut être enrichi avec des fonctionnalités supplémentaires (défilement auto, swipe mobile, pagination, etc.) ou intégré dans un site plus vaste.

---

## 🚀 Mise en route  

1. Clone ou télécharge le projet  
2. Place tes images dans `/assets` (en suivant la convention `Carousel1.jpg`, etc.)  
3. Lance `index.html` dans un navigateur  

Aucune installation ou dépendance nécessaire. Juste du code simple qui fonctionne.
